# Zenodo Deposit Guide — v1.0.1-preprint

No Zenodo draft, DOI reservation, upload, or deposit has been created.

## Proposed files

Upload together:

1. `ONE_PAGE_RESEARCH_SUMMARY.pdf`
2. `PUBLIC_RESEARCH_REPORT.pdf`
3. `TECHNICAL_RESEARCH_PAPER.pdf`
4. the verified source-and-publication archive prepared for the GitHub release
5. the release checksum ledger

Use `zenodo_metadata.json` as the human-readable metadata source. Set the
publication date to the date the materials first become publicly available.
Do not add an ORCID, affiliation, funding source, peer-review claim, or DOI that
has not been verified.

## DOI and publication

Zenodo can reserve a DOI in a draft, but the DOI is registered when the record
is published. Reserving a DOI, uploading files, changing visibility, or
publishing the record each requires explicit authorization for this project.

Official instructions checked 2026-11-24:

- https://help.zenodo.org/docs/deposit/create-new-upload/
- https://help.zenodo.org/docs/deposit/describe-records/reserve-doi/
- https://help.zenodo.org/docs/deposit/describe-records/licenses/
